# Fonts

`PixelifySans.ttf` is **Pixelify Sans** (variable font, Regular–Bold), Copyright 2021 The Pixelify Sans Project
Authors (https://github.com/eifetx/Pixelify-Sans). It is licensed under the SIL Open Font License 1.1; the full
license is in `OFL.txt` next to it. Downloaded unmodified from the Google Fonts repository
(`ofl/pixelifysans/PixelifySans[wght].ttf`) and renamed.

SHA-256 `9ba86cd010a4de309d263ceff8e8044092c9db7efda869620cb9ff1c4389e8a5`

The viewer renders it without antialiasing at 13, 14 and 16 px, where its strokes land on whole pixels. If the
file is missing, the viewer falls back to pygame's default font.
