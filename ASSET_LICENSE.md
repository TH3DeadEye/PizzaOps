# PizzaOps artwork — usage and credits

This pack was created for the PizzaOps project. The furniture, food, decor, and six characters are original generated artwork produced with the built-in image-generation tool, then exported as isolated sprites with cleaned alpha, consistent canvas sizes, registration points, and animation metadata. The modular geometry and small UI graphics are original programmatically authored pixel artwork. No third-party game sprites, screenshots, logos, or purchased asset packs were incorporated.
